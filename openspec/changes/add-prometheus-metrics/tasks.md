## 2. The platform package and its three source rules

- [ ] 2.1 `internal/platform/metrics`: one explicit `prometheus.NewRegistry()` held as process-wide state, a `Handler()` over it via `promhttp.HandlerFor`, and registration of `collectors.NewGoCollector()` and `NewProcessCollector()` into it explicitly. No package in this repository may name `promauto`, `prometheus.DefaultRegisterer`, `DefaultGatherer`, or the package-level `Register`/`MustRegister`.
- [ ] 2.2 The two label constructors, `Route(string) string` and `Method(string) string`, each **total**: every input returns a member of a bounded set, with `<unmatched>` and `UNRECOGNIZED` as the fallbacks. `UNRECOGNIZED` reuses the access record's own spelling (`cmd/video-api/logging.go:63`) deliberately — the same fact should read the same in a record and in a series.
- [ ] 2.3 `BindRoutes(gin.RoutesInfo)`, called once per root at the end of `setupRouter`. Cover the failure mode directly: with `BindRoutes` never called, `Route` must return `<unmatched>` for everything rather than passing values through — a fail-closed empty table, not an absent one.
- [ ] 2.4 `internal/platform/metrics/disclosure_test.go`, modelled on the logging walk and carrying its two hard-won guards: skip `fs.ErrNotExist` rather than returning `WalkDir`'s error verbatim (the #251 race, still live — the ffmpeg tests create and remove `temp/<jobID>` under their own package directory), and **fail loudly if it parses no file**, so a moved tree cannot report every rule clean while checking nothing.
- [ ] 2.5 Rule 1 — every label value is a string literal or a call to `metrics.Route`/`metrics.Method`. Cover all three sites a label value can reach: `WithLabelValues` arguments, `prometheus.Labels{…}` composite-literal values, and `MustNewConstMetric`'s trailing arguments. A walk that checks only the first passes while the collector in task 5 leaks.
- [ ] 2.6 Rule 2 — every metric name, help string and label-name list entry is a string literal.
- [ ] 2.7 Rule 3 — the default-registry ban of 2.1, enforced as an import ban on `promauto` **plus** a name ban on the three `prometheus.`-qualified defaults. An import ban alone misses `prometheus.MustRegister(c)`; a name ban alone misses `promauto.NewCounterVec(…)`, which registers into the default registry without naming it.
- [ ] 2.8 Drive the walk over synthetic sources for every form the repository does not contain yet, the way `TestTheWalkJudgesEachFormItMustJudge` does — at minimum: a label value from `strconv.Itoa`, from a `const`, from a variable, from `fmt.Sprintf`; a `prometheus.Labels` map with one literal and one variable value; a `MustNewConstMetric` with a variable label; `promauto` by import; `prometheus.MustRegister`; and the two permitted constructors, which must pass. A rule never seen rejecting something is a rule of nothing.
- [ ] 2.9 See each rule fail before it passes, on the real tree: add a violating call site temporarily, confirm the test names the file and line, remove it.

## 5. The pipeline collector and the one new index

- [ ] 5.1 Add the partial index `ON video_jobs (created_at) WHERE status = 'queued'` to `internal/video/infrastructure/postgres/schema.sql`, beside the `processing` one and carrying a comment in the same terms. Confirm the file stays argument-free — pgx forces the simple query protocol for an argument-free `Exec`, and a parameter introduced into this file breaks startup rather than one table.
- [ ] 5.2 Two aggregate queries in that package: per-state count and oldest `created_at` over `video_jobs` for `queued` and `processing`; per-`event_type` count and oldest `occurred_at` over `video_job_outbox WHERE published_at IS NULL`, restricted to the relayed event types. Restrict the second with the same closed set the relays claim on — an unrestricted version reports the permanent `video_job.created` backlog and climbs forever.
- [ ] 5.3 `EXPLAIN` both statements against a populated database and confirm each is served by a partial index. This is the task that is wrong in a way that looks like a working system: an unindexed aggregate returns the right number and reads the whole table every scrape, forever.
- [ ] 5.4 The count saturates at a stated bound (a bounded subquery); the oldest-age lookup does not and must be a one-row index read. Assert the saturation explicitly with more rows than the bound.
- [ ] 5.5 **On a query failure, emit no value and report the failure to the scraper** — `prometheus.NewInvalidMetric`, never `0`. Cover it: with the pool closed, assert the gathered output carries no `fiapx_video_jobs_in_state` sample and that the scrape reports an error. A collector that answers `0` under failure is the single most misleading thing this change could ship.
- [ ] 5.6 Bound `Collect` with its own context timeout, and confirm the bound is strictly below whatever scrape timeout is used — the same relationship `service-health-probes` states between a readiness check and its prober, and wrong in the same silent direction.
- [ ] 5.7 Register the collector only in `cmd/video-api`. It reads the video pool; no other process should hold it, and `cmd/worker` holding it would put a query-per-scrape on a process nothing scrapes.
